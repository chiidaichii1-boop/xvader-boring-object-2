## Entry

`main.py` (Python 3, standard library only) writes one line — a funny,
true review of a doorstop — to `/output/entry.txt`:

> The doorstop: hired to do nothing but sit in a corner, and somehow still
> the most reliable thing in the office — it has never once called in sick.

## Run

```sh
python3 main.py
```

It reads `MAKEFUN_INPUT_DIR` / `MAKEFUN_OUTPUT_DIR` (falling back to
`/input` / `/output`), creates the output directory if missing, and writes
`entry.txt` deterministically.
